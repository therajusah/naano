# Agent logs

This directory captures the AI coding agent's prompts and responses for the Naano clone build.

## Contents

- `session-01-transcript.md` — human-readable chronological transcript (prompts, responses, tool calls).
- `raw/session-01.jsonl` — full-fidelity main session transcript.
- `raw/agent-*.jsonl` — the 8 parallel sub-agent transcripts (marketing, free-tools, auth, company,
  creator, agency, etc.).

Obvious secret patterns (API keys, auth secrets) have been redacted for public safety.
